## 1. 产品概述

### 1.1 项目背景

运营后台是邻动体适能小程序的内部管理工具。当前家长端主业务已从早期“单次课程拼团”升级为“5 节课程拼团”，后台也以课包 / package 模型为主，负责配置课程、团型售价、地点、教练、上下架、拼团记录、订单退款和操作日志。

### 1.2 产品定位

一个面向内部运营人员的 Web 管理后台，用于支撑小程序课程拼团日常运营，保证课程信息准确、订单处理及时、退款可追溯、后台账号安全可控。

### 1.3 当前业务边界

- 当前后台主导航为：概览、课包管理、课包拼团、课包订单、账号管理、操作日志。
- 旧的单次课程、单次拼团、单次订单服务和页面代码仍保留，但不作为当前主运营入口。
- 家长端前台统一使用“课程”文案；后台和接口字段仍沿用“课包 / package”命名。
- 后台只负责配置和管理，不直接代替用户开团或参团。
- 高风险操作如手工改团人数、手工改团状态、脱离订单直接加人，当前不纳入范围。

## 3. 登录与权限

### 3.1 登录

- 登录页包含用户名、密码、登录按钮。
- 验证成功后进入概览页，并保存后台 token。
- 验证失败提示“用户名或密码错误”或服务端返回错误。
- 后台所有页面均需登录后访问。
- token 过期或无 token 时跳转登录页。

### 3.2 角色权限

- `super_admin`：可访问全部模块，包括账号管理。
- 普通管理员：可访问概览、课包管理、课包拼团、课包订单、操作日志，不展示账号管理入口。
- 直接访问无权限页面时，应重定向到概览或展示无权限提示。

### 3.3 账号管理

账号列表：

- 展示用户名、角色、状态、最后登录时间、创建时间、操作。
- 支持按用户名、角色、状态筛选。
- 支持分页。

新增账号：

- 字段：用户名、密码、确认密码、角色。
- 密码至少 6 位。
- 密码需加密存储。

编辑账号：

- 用户名不可修改。
- 可更新角色、状态。
- 修改密码时需填写确认密码。

删除账号：

- 二次确认后删除。
- 至少保留一个超级管理员账号。

## 4. 概览

### 4.1 页面定位

概览页是后台首页，帮助运营快速了解课包业务状态与异常。

### 4.2 时间范围

- 今日。
- 近 7 天。
- 近 30 天。
- 近 7 天 / 近 30 天均为含今日的连续自然日。

### 4.3 课包核心指标

- 当前已上架课包数。
- 当前范围内新增课包数。
- 当前范围内成功成团数。
- 当前范围内已支付成员数。
- 当前范围内课包实付金额。
- 当前范围内已退款订单数。

### 4.4 异常提示

- 失败团仍存在未退款订单。
- 已过截止时间但仍显示进行中的团。
- 团人数与成功订单数不一致。
- 当前范围内系统自动退款订单数。

### 4.5 下钻

概览卡片可下钻到对应列表，并自动带上默认筛选：

- 已上架课包 -> 课包列表 `status=active`。
- 成功成团 -> 课包拼团列表 `status=success`。
- 已支付成员 / 实付金额 -> 课包订单列表 `status=success`。
- 已退款订单 -> 课包订单列表 `status=refunded`。
- 异常团 -> 课包拼团或课包订单列表。

## 5. 课包管理

### 5.1 课包列表

列表字段：

- 课包名称。
- 课包类型。
- 总价参考价。
- 节数 / 单节时长。
- 支持团型。
- 地点。
- 教练。
- 状态。
- 上架时间。
- 操作：查看、编辑、查看拼团、查看订单、下架。

筛选：

- 课包名称关键字。
- 课包类型：体适能 / 跳绳。
- 状态：待上架 / 已上架 / 已下架。
- 分页。

操作：

- 新建课包。
- 查看课包详情。
- 编辑课包。
- 查看该课包拼团。
- 查看该课包订单。
- 下架课包。

### 5.2 课包状态

状态枚举：

- `pending`：待上架。
- `active`：已上架。
- `inactive`：已下架。

状态规则：

- 新建课包必须填写上架时间。
- 当前时间早于上架时间时为 `pending`。
- 当前时间到达或晚于上架时间时为 `active`。
- 人工下架后立即变为 `inactive`。
- `inactive` 为人工终态，优先级最高，不因时间到达自动恢复。
- 小程序首页只展示 `active` 课包。
- 已下架课包如已有成功拼团，家长仍可访问对应拼团详情。

### 5.3 课包表单

基本信息：

- 课包名称，必填。
- 课包类型，必填，当前支持体适能 / 跳绳。
- 封面图，必填。
- 课程介绍，必填，支持上传图片后插入 HTML。

价格与课时：

- 总价参考价，必填，单位分，作为运营参考价。
- 课程节数，必填，`class_count > 0`。
- 单节课时长，必填，单位分钟，`class_duration_minutes > 0`。
- 团型售价配置，必填，至少 1 条。
- 每条团型售价配置包含：目标人数 `target_count`、人均售价 `price_fen`。
- `target_count` 必须为正整数。
- `price_fen` 必须为正整数。
- 同一课包内 `target_count` 不允许重复。
- 支持团型 `supported_people` 由团型售价配置自动派生，不再作为主输入项。

时间与规则：

- 上架时间 `publish_time`，必填。
- 下架时间 `unpublish_time`，系统下架后写入。
- 开团截止时长 `deadline_hours`，默认 48 小时，可配置。
- 课包拼团截止时间按“开团支付成功创建团时间 + deadline_hours”生成。

地点：

- 所在区域，后台可通过省 / 市 / 区三级选择或地图回填。
- 小区 / 场地名称，必填。
- 详细地点，必填。
- 经度、纬度，可由地图联想或地理编码回填。
- 详细地点输入支持腾讯地图地点联想搜索。
- 选择地点候选后自动回填详细地点、经纬度、省 / 市 / 区。
- 若未选择候选，可通过“解析经纬度”执行地理编码。
- 家长端展示不展示省级信息，但后台仍可保存省 / 市 / 区用于管理和定位。

教练：

- 教练姓名，必填。
- 教练简介，必填，支持上传图片后插入 HTML。
- 教练证书，多图，选填。

图片：

- 当前课包不单独维护轮播图。
- 详情页顶部主图由封面图兜底。
- 服务端可在读取层使用 `cover` 回填 `images`。

### 5.4 课包金额口径

- `total_price` / `total_price_fen` 为总价参考价，不作为实际支付金额的主来源。
- `group_price_config` 为各团型人均支付金额的主来源。
- 课包详情页支持拼团金额直接读取 `group_price_config`。
- 小程序首页 `¥X起` 取 `group_price_config` 中最低人均售价。
- 开团 / 参团下单金额按目标团型读取 `group_price_config.price_fen`。
- 仅兼容历史数据且团型配置缺失时，允许回退到 `total_price / target_count`。
- 前台金额展示按去尾零规则；后台表单与列表金额可保留两位小数以便运营核对。

## 6. 课包拼团管理

### 6.1 列表

列表字段：

- 拼团 ID。
- 所属课包。
- 目标人数。
- 当前人数。
- 状态。
- 上课时间规则。
- 截止时间。
- 创建时间。
- 成团时间。
- 操作。

筛选：

- 课包 ID / 课包名称。
- 拼团状态：进行中 / 已成团 / 已失败。
- 分页。

入口：

- 独立导航“课包拼团”查看全量。
- 从课包列表或详情进入时，自动带上 `package_id`。

### 6.2 状态与规则

状态枚举：

- `active`：进行中。
- `success`：已成团。
- `failed`：已失败。

规则：

- 开团支付成功后才创建 `package_group`。
- 创建团时 `current_count = 1`。
- 团长对应订单状态为 `success`。
- 参团支付成功后当前人数 +1。
- 当前人数达到目标人数后，团状态变为 `success`。
- 成团后锁定首课时间，并生成 5 次课程安排。
- 到达 `deadline` 仍未成团时，团状态变为 `failed`。
- 失败团触发已支付订单自动退款。
- 后台只读展示团状态，不允许人工直接改团状态、团人数或成员。

### 6.3 异常提示

拼团详情或列表应能辅助排查：

- 失败团仍存在未退款成功订单。
- active 团已过截止时间。
- 当前人数与成功订单数不一致。
- 已成团但缺失首课时间。

## 7. 课包订单管理

### 7.1 列表

列表字段：

- 订单号。
- 用户昵称。
- 用户手机号：当前前台不采集手机号，后台展示为空或“未同步手机号”。
- 课包名称。
- 拼团 ID。
- 支付金额。
- 订单状态：待支付 / 已支付 / 已退款 / 已关闭。
- 支付时间。
- 退款时间。
- 退款类型。
- 退款原因。
- 操作：查看详情、手动退款。

筛选：

- 订单号。
- 用户昵称。
- 课包名称。
- 订单状态。
- 退款类型：系统自动退款 / 手动退款。
- 时间范围：下单时间 / 支付时间 / 退款时间。
- 支持按 `package_id` 从课包详情或课包列表带入筛选。
- 分页。

### 7.2 订单详情

展示：

- 订单基本信息。
- 用户信息。
- 课包信息。
- 拼团信息。
- 支付信息。
- 退款信息。
- 退款原因与退款类型。

### 7.3 手动退款

允许范围：

- 仅允许对 `success` 订单发起。
- 已成团团不支持个人线上退款。
- 已退款、已关闭、待支付订单不可重复退款。

交互：

- 点击手动退款后弹出确认区域或弹窗。
- 需填写退款原因。
- 确认后调用退款接口。

退款后处理：

- 订单状态变为 `refunded`。
- 记录退款时间、原因、操作人。
- 同步标记支付记录退款。
- 若退款发生在未成团进行中团，需回滚当前人数和相关团状态。
- 记录操作日志 `package_order_refund`。

自动退款展示：

- 拼团失败导致的退款展示为“系统自动退款”。
- 手动发起的退款展示为“手动退款”。

## 10. 非功能需求

- 所有后台页面需登录鉴权。
- 列表查询支持分页，筛选后翻页保留条件。
- 列表接口目标响应时间小于 500ms。
- 表单提交需服务端校验，不能仅依赖前端。
- 退款接口需幂等，防止重复退款。
- 关键操作必须写入操作日志。
- 支持 Chrome、Edge、Safari 最新版。

## 11. 验收标准

### 11.1 登录与权限

- 正确账号密码可登录。
- 错误密码无法登录。
- 未登录访问后台页面会跳转登录。
- 普通管理员看不到账号管理入口。
- 普通管理员直接访问账号管理时不能进入。

### 11.2 概览

- 今日 / 近 7 天 / 近 30 天切换正常。
- 核心指标展示正确。
- 异常提示展示正确。
- 概览下钻能进入对应列表并回显筛选。

### 11.3 课包管理

- 可新建、编辑、查看、下架课包。
- 课包列表筛选和分页正常。
- 团型售价配置可增删，且可自动派生支持团型。
- 表单校验能拦截缺失字段、重复团型、非法金额、非法课时。
- 地点联想搜索和经纬度解析可正常回填。
- 课包介绍和教练简介支持图片插入。
- 下架后课包不再出现在小程序首页。

### 11.4 课包拼团

- 可查看全量课包拼团。
- 可按状态和课包筛选。
- 从课包列表进入拼团列表时能带上课包筛选。
- 进行中、已成团、已失败状态展示正确。
- 拼团截止时间符合“开团支付成功创建团时间 + deadline_hours”。
- 异常团能在概览或列表中辅助识别。

### 11.5 课包订单

- 可查看课包订单列表和详情。
- 可按订单号、用户、课包、状态、退款类型、时间范围筛选。
- 未采集手机号时展示“未同步手机号”或为空。
- `success` 且未成团限制允许范围内的订单可手动退款。
- 已退款、已关闭、待支付订单不可重复退款。
- 退款后订单状态、退款时间、退款原因、支付记录和操作日志正确更新。

### 11.6 操作日志

- 课包创建、编辑、下架写入日志。
- 课包订单退款写入日志。
- 账号关键操作写入日志。
- 日志筛选和分页正常。
